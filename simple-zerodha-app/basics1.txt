html tag defines the root of html document.
<html> tag is the container for all html elements.

head tag contains metadata about the document.
metadata means information about the data or the web page like title,description etc.

body tag contains all the visible content of the web page.
for eg: text,images,paragraphs,links etc.

div tag
div meant division.
div tag defines a division or section in html document.
div tag is used as container for html elements, which then can be styled using css and manipulated using js.
