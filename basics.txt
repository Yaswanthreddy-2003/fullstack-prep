browser
browser is a sofware application that is used to access,view and interact with websites on internet.
eg: chrome,firefox,edge
Abrowsers takes websites(HTML,CSS,JS) and render them into visual content that we can interact with.

Rendering
Rendering is the process by which a browser converts html,css and js code into pixels(visual content) on the screen.
pixel is the smallest unit of a digital image.

How browsers render a websites
Step 1. Fetching
      You enter a URL, browser sends request to the server
      Server responds with html,css,js,images

Step 2. Parsing
      Browser parses the HTML code andconverts into DOM tree.
      DOM tree is a tree-like structure that represents the structure of a web page.
      Browser creates CSSOM(css object model)
      CSSOM is a tree like structure that represents the style of a web page.
      Browser then combines DOM and CSSOM to create render tree.
      Render tree is a tree-like structure that represents the visual structure of a web page.

Step 3. Layout
     Browser calculates size and position of each element in the page.
     Painting:
     Browser fills pixels: colors,texts,borders,images etc.

Step 4: JavaScript Execution
     Browser executes JavaScript code.
     JavaScript can modify the DOM and CSSOM.
